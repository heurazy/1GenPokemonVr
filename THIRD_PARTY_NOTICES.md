# Third-party source

## Dramatic Shape Voxel Mod

Project and current upstream release:
https://github.com/DramaticShape/DramaticShapeVoxelMod/releases/tag/v1.4.0

`mods/dramatic_shape` is derived from
`DramaticShape/DramaticShapeVoxelMod` at commit
`acc66b51bbf1cbab7096108e6a2abcc8f23a48a1`.

The VR integration adds per-eye OpenXR camera projection and stereo render
targets while retaining the original voxel terrain, character, shadow and
tilt-shift implementation.

At the time this integration was made, the upstream repository did not
contain a license file. Redistribution therefore requires permission from
its copyright holder.
